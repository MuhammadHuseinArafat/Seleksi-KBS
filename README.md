# Seleksi KBS Informatika

Pembaca soal seleksi berbasis web dengan satu tampilan per soal, layar identitas peserta, petunjuk pengerjaan, dan timer ujian 80 menit.

## Menjalankan secara lokal

Pastikan Node.js terpasang, lalu jalankan:

```sh
npm install
npm run dev
```

Vite akan menampilkan alamat lokal aplikasi di terminal.

## Build produksi

```sh
npm run build
npm run preview
```

PDF revisi `SOAL SELEKSI KBS (1).pdf` digunakan sebagai sumber soal. Repository ini bersifat publik, jadi PDF dapat diakses dan diunduh siapa saja.
